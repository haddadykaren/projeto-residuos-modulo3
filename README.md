# Projeto Resíduos - Condomínio Residencial Glagau

Projeto desenvolvido para a avaliação do Módulo 3 - Banco de Dados e Controle de versão, do Programa de Extensão UFMS Digital.

## Objetivo

Criar uma estrutura de banco de dados para organizar informações relacionadas ao descarte de resíduos no Condomínio Residencial Glagau.

## Estrutura

- `banco/criacao_tabelas.sql` - criação das tabelas e restrições.
- `banco/inserts.sql` - dados utilizados nos testes.
- `banco/consultas.sql` - consultas e operações de manipulação.
- `modelo/modelo_banco.png` - diagrama do banco de dados.

## Entidades

- Morador
- Categoria
- Material
- Registro de Descarte

## Tecnologias

- PostgreSQL
- SQL
- Git
- GitHub

## Continuidade

O projeto dá continuidade à aplicação web desenvolvida no módulo anterior sobre conscientização do descarte correto de resíduos.
